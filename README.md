# Beat saber

## Risketos Bàsics

- [x] Lectura i reproducció d’un fitxer d’àudio al projecte.
- [x] Sistema que genera objectes segons un patró predefinit o manual seguint el ritme.
- [x] Detecció de col·lisions o cops amb els controllers (espasa, pal, etc.).
- [ ] Feedback audiovisual sincronitzat amb el ritme (sons, partícules, canvis de color o llum).
- [x] Sistema de puntuació bàsic segons precisió o nombre d’encerts.


## Risketos Opcionals

- [ ] Generació procedimental del bitmap de la música.
- [ ] Nivells de dificultat que facin patrons diferents
- [ ] Diferents objectes com bombes, parets o cubs que es mouen.
- [ ] L’entorn varia depenent del ritme de la música.
- [ ] Fer el joc en AR.
- [ ] Gestió de escenes ben muntat.
